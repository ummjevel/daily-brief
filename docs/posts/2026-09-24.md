## 오늘의 경제 뉴스

**제목**: AI 입혀 매출 30조위안으로…中 경공업 성장 공식 바꾼다 [차이나 워치]
**출처**: 한국경제 (2026-09-24)
**원문**: https://www.hankyung.com/article/202609233495i

### 한 줄 요약
중국 공업정보화부 등 3개 부처가 경공업·섬유산업 제15차 5개년 계획을 통해 2030년까지 일정 규모 이상 기업 매출 30조위안, 1인당 노동생산성 40만위안 달성을 목표로 내놨습니다. 핵심은 '싸게 많이 만들기'에서 벗어나 AI·자동화·브랜드·친환경 전환으로 무게중심을 옮기는 것으로, 업종별 특화 AI 모델과 전용 AI 에이전트를 기획부터 유통까지 하나의 데이터 체계로 연결하겠다는 구상입니다. 비용 상승, 환경 규제, 글로벌 공급망 재편이라는 삼중 압박이 이 전환의 배경으로 지목됩니다.

### 핵심 개념

- **노동생산성 (Labor Productivity)**
  노동생산성은 근로자 한 명이 일정 기간에 만들어내는 부가가치의 크기입니다. 이번 계획의 '1인당 40만위안'은 사람 수를 늘려 생산량을 키우는 방식(투입 확대)이 아니라, 같은 사람이 더 값나가는 결과를 내도록 만들겠다는 선언입니다. 똑같은 재봉사 한 명이 무명 티셔츠를 하루 100장 박는 것과, 디자인·소재·브랜드가 붙은 옷을 20장 만드는 것의 차이라고 보면 됩니다. 인구가 줄고 임금이 오르는 나라에서 성장을 이어가려면 결국 이 지표를 올리는 수밖에 없어서, 고령화 국면에 들어선 중국이 여기에 목표치를 못 박은 것은 자연스러운 수순입니다.

- **글로벌 가치사슬과 고부가가치 전환 (Global Value Chain / Moving Up the Value Chain)**
  하나의 제품이 기획→설계→부품→조립→브랜드·유통으로 이어지는 국제 분업 사슬을 글로벌 가치사슬이라고 합니다. 이 사슬에서 이익은 양끝(설계·브랜드)에 몰리고 가운데(조립·봉제)는 얇게 남는 '스마일 커브' 구조여서, 중국은 지금까지 가장 이익이 얇은 구간을 가장 크게 차지해온 셈입니다. 기사에서 경공업·섬유가 중국 공업기업 수의 34.5%, 수출의 32%를 차지하면서도 매출 비중은 19.8%에 그친다는 수치가 바로 그 증거입니다. 브랜드 600개, 산업 클러스터 550개 같은 목표는 사슬의 양끝으로 올라서겠다는 의도입니다.

- **수직형 AI 모델과 기술 자립 (Vertical AI Model / Technological Self-Reliance)**
  수직형 AI 모델은 모든 걸 다루는 범용 AI가 아니라 염색 공정, 편직 설계처럼 특정 업종의 데이터와 노하우만 집중 학습시킨 특화 모델입니다. 동네 종합병원 대신 그 질병만 20년 본 전문의를 두는 것에 가깝고, 공장 현장에서는 범용 모델보다 실제로 쓸 만한 답을 내놓는 경우가 많습니다. 여기에 중국은 해외 의존도가 높은 핵심 소재·첨단 장비를 따로 지정해 국산화를 지원하겠다고 했는데, 이는 공급망이 끊겨도 버틸 수 있는 체력을 뜻하는 기술 자립 전략입니다. 다만 효율만 보면 잘하는 나라에서 사 오는 게 싸기 때문에, 자립은 언제나 '비용을 더 내고 안전을 사는' 거래라는 점은 짚어둘 필요가 있습니다.

### 왜 중요한가
중국 경공업·섬유가 저가 경쟁에서 디자인·브랜드·스마트 제품 영역으로 올라오면, 한국의 소비재·화장품·생활가전·패션 기업은 지금까지와 다른 층위에서 경쟁하게 됩니다. 동시에 고령자용품·영유아용품·반려동물용품·스마트홈 같은 8대 중점 분야는 한국 기업이 이미 경쟁력을 갖춘 영역과 상당 부분 겹쳐, 대중국 수출 기회이자 정면 충돌 지점이 됩니다. 5년 계획은 중국에서 실제 예산과 보조금이 따라붙는 문서인 만큼, 2030년을 향한 이 방향 전환은 우리 산업의 중기 전략을 다시 점검해야 할 신호로 읽는 편이 안전합니다.

## 오늘의 비즈니스 영어

**표현**: "Let's align on..."
**상황**: 여러 팀·역할이 얽힌 설계/스펙 논의에서 세부 작업에 들어가기 전에 공통된 이해나 우선순위를 먼저 맞추자고 제안할 때

**뜻**: "~에 대해 서로 의견/이해를 맞추자"는 뜻으로, 구체적인 실행에 들어가기 전에 방향성이나 경계, 우선순위에 대한 합의를 먼저 확보하자는 표현입니다. "일치시키다"보다는 "같은 그림을 보고 있는지 확인하자"에 가깝습니다.

**왜 지금**: 오늘 InfoQ 기사 "Presentation: APIs for Agents: Rethinking API Programs in the MCP Era"에서 Morgan Stanley 팀이 MCP와 A2A 통신을 통합하면서 API 소유권과 거버넌스 규칙을 팀 간에 명확히 하는 과정을 다루는데, 바로 이런 다자간 아키텍처 논의에서 실행에 앞서 "누가 무엇을 책임지는지" 먼저 맞추는 상황에 "align on"이 정확히 들어맞습니다.

**쓰는 법**:
- 격식 중간~높음. 스탠드업, 디자인 리뷰, 이메일, 고객 미팅 어디서나 자연스럽고, 특히 여러 팀이 얽힌 논의를 시작할 때 회의의 톤을 정리해주는 표현입니다.
- 한국어 화자는 이걸 "let's match our opinions" 혹은 "let's synchronize our thoughts"처럼 직역해서 어색하게 쓰는 경우가 많습니다. 원어민은 거의 항상 "align on"을 씁니다.

**업무 예문**:
1. [스펙 논의] Before we start the API design, let's align on ownership boundaries between the agent and the MCP server.
   → API 설계를 시작하기 전에, 에이전트와 MCP 서버 간 소유권 경계에 대해 먼저 의견을 맞춰봅시다.
2. [1:1] Can we align on priorities for this sprint before I start coding?
   → 제가 코딩을 시작하기 전에 이번 스프린트 우선순위에 대해 서로 맞춰볼 수 있을까요?
3. [이메일] I want to make sure we're aligned on the rollout timeline before the customer call.
   → 고객 미팅 전에 롤아웃 일정에 대해 우리가 같은 생각인지 확인하고 싶습니다.

**바꿔 쓸 수 있는 표현**:
- **be on the same page** — "같은 이해를 공유하고 있다"는 상태를 강조하는 캐주얼한 표현으로, 합의 과정보다는 결과에 초점
- **sync up on** — 정보 공유 성격이 강한 짧은 미팅에 어울리며, "align on"만큼 결정적/공식적인 뉘앙스는 없음
- **get everyone on the same wavelength** — 매우 캐주얼하고 구어체적이며, 공식 문서나 이메일에는 잘 안 씀

## 오늘의 중국어 회화 — 음식·식당

**문장**: 面条
**병음**: miàn tiáo
**뜻**: 국수

**단어별 풀이**:
- **面 (miàn)** — 면, 국수
  · 원래 '얼굴'이라는 뜻도 있지만 음식에서는 밀가루로 만든 '면'을 의미해요.
- **条 (tiáo)** — 가늘고 긴 것
  · 길쭉한 모양의 물건(국수, 길 등)을 세는 단위이자 그 모양 자체를 나타내요.

**함께 알면 좋은 표현**:
- **面包 (miànbāo)** — 빵
- **我要面条 (Wǒ yào miàntiáo)** — 저는 국수를 원해요
- **汤面 (tāngmiàn)** — 국물 국수

**오늘의 한자**: 条
- 구성: 나뭇가지(木)에서 뻗어 나온 가늘고 긴 모습에서 유래한 글자예요.
- 직관적 이미지: 나뭇가지처럼 길고 가늘게 늘어진 모양 → 국수 가락을 떠올리면 기억하기 쉬워요.
- 다른 단어 예시: 一条 (yì tiáo, 하나의 길고 가는 것), 面条 (miàntiáo, 국수)
